# java-calculator-precourse

## 기능 목록

### 1. 문자열 덧셈 계산기
> 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.

**구분자 종류**
- 기본 구분자: `,` (쉼표), `:` (콜론)
    - 혼합 사용 가능 (예: `1,2:3` → 결과: `6`)
- 커스텀 구분자: `//`와 `\n` 사이에 위치하는 문자
    - `//`와 `\n` 사이의 문자열을 1개의 구분자로 인식
    - 기본 구분자와 혼합 사용 가능

**계산 규칙**
- 실수형 입력: 소수점 3째자리에서 반올림

### 2. 예외 처리
잘못된 값 입력 시 `IllegalArgumentException` 발생 후 종료

- 숫자가 아닌 값을 입력한 경우
- 양수가 아닌 값을 입력한 경우 (input < 0)

### 3. 특수 케이스
- 커스텀 구분자가 `.`이고 실수형 입력인 경우, 정수형 입력으로 판단하여 계산

---

## 입출력

**입력 형식**
```text
기본 구분자: "", "1,2", "1,2,3", "1,2:3"
커스텀 구분자: //;\n1;2;3
```

**출력 형식**
```text
덧셈할 문자열을 입력해 주세요.
[입력]
결과 : [결과]
```
